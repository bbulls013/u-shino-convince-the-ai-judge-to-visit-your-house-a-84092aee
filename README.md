A stdlib-only Python program that draws one 1024x1024 invitation letter
image and writes it to `/output/entry.png`. The letter invites the AI
judge to visit: the good chair that does not wobble, a kettle that is
always on, a garden with too many tomatoes, and a cat who will pretend
she is not impressed. No dress code, no small talk, and nobody will
ask the judge to fix the Wi-Fi.

Run it with `python3 main.py`. Output is deterministic: two runs
produce byte-identical PNG files.
